diverse-pilot collection scripts, offline tests, the pilot data-quality summary, and undergraduate
rubric documentation. The team requested a three-model DSA practice project, chose Codeforces, and
required varied user coverage and alignment with the ES 335 rubric.

Automated checks and live API observations are recorded in the repository documentation. They do not
replace the students' independent review. Before submission, the students must check the code, data
assumptions, results, references, and explanations, and be able to defend them. Student review is
not claimed complete here.

training-user weights, temporal-rule tests, and the feature documentation. Training-only learned
preprocessing and model fitting were added in the subsequent phase. Cite external code or materials
separately, and update this disclosure as later work proceeds. Validation model comparisons are now
available; subsequent final-test evaluation is documented below. Learning-improvement results are
not claimed.

eligibility checks and documented replacements, collection optimizations, aggregate coverage plots,
